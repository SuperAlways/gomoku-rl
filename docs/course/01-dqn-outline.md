# 课 01 · DQN——从乱走到会下棋（实验清单）

> 本课原则：**一次把 DQN 的能力空间全部走完**——概念验收 → 基础 CNN → 部件消融 → 衍生型 → 奖励设计 → 预训练。之后换任何算法（REINFORCE/PPO/AlphaZero）时，"它解决了 DQN 的什么痛"直接指认实验编号即可。
>
> 每个实验统一记录四件套：逐代基准赛胜率（vs minimax 三档各 20 局）/ 平均局长 / loss 曲线 / 策略熵。全部落库归档（M6 训练档案雏形）。

## A. 概念验收

### E0 表格 Q-learning（3×3 连三制）
- **设置**：Q 是一张 dict 表，ε-greedy，vs 固定对手（minimax depth1），CPU 几分钟
- **你应该会看到**：Q 表从全 0 到结构化（天元价值最高）；agent 对固定对手从必输到不败
- **验收概念**：Q 更新公式、TD 靶子、ε-greedy、稀疏奖励回填——整条环路亲眼看清
- **意义**：机制 bug 在 3×3 五分钟暴露，在 15×15 要烧几小时

## B. 基础 CNN + 稀疏奖励的"最初开始"

### E1 完整配方基线（15×15，对照组）
- **设置**：2 特征平面（己方/对方）小 CNN → 224 Q 值；replay buffer + target network + ε 退火；对手池；纯稀疏终局奖励（赢家 +1 / 输家 -1 / 平 0）
- **你应该会看到**：胜率曲线长期贴地、平均局长先变长（学会拖延）再变短；若干代后开始爬升
- **意义**：体验稀疏奖励在大棋盘上的真实难度；这条曲线是后面所有实验的参照物

## C. 部件消融（每次只动一个开关）

### E2 拆掉 replay buffer
- **设置**：在线单样本更新（batch=1，用完即弃）
- **你应该会看到**：loss 剧烈震荡；已学会的应对突然消失（灾难性遗忘）
- **概念**：经验回放打破时间相关性

### E3 拆掉 target network
- **设置**：TD 靶子直接用主网络
- **你应该会看到**：Q 值持续抬升发散、loss 爆炸、胜率崩塌（追逐自己的尾巴）
- **概念**：滞后靶子稳定 TD 学习

### E4 探索率消融
- **设置**：ε 恒定 0.5 / 线性退火 0.5→0.05 / ε=0
- **你应该会看到**：ε=0 早早僵死在固定开局且被针对；恒定 ε 晚期胜率上不去；退火最优
- **概念**：exploration-exploitation 权衡

### E5 对手池消融（非平稳性）
- **设置**：只打"最新的自己" vs 打池（历史 checkpoint + minimax 混编）
- **你应该会看到**：只打自己：专精针对上一代的一个开局、对其他对手整体退化（自对弈循环）
- **概念**：自对弈的策略非平稳性；对手池 = 解药

### E6 网络容量消融
- **设置**：输入 2 平面 vs 4 平面（+最后落子位置 one-hot、+历史一手）；宽窄两档 CNN
- **你应该会看到**：太窄欠拟合（train loss 高不下去）；太大样本效率反而差；4 平面显著加速
- **概念**：表示能力与样本效率的权衡

### E7 γ 折扣因子消融
- **设置**：γ = 0.9 / 0.99 / 0.999
- **你应该会看到**：γ 小 → 短视（不布局、不挡四）；γ 大 → 早期不稳定
- **概念**：折扣 = 看多远的未来

## D. 衍生型（同一个框架再拧两个旋钮）

### E8 Double DQN
- **设置**：动作选择用主网络、估值用 target 网络（解耦 argmax 与 bootstrap）
- **你应该会看到**：Q 值过估计明显减轻（对比 E1 的 Q 值分布），中后期更稳
- **概念**：过估计与解耦

### E9 Dueling DQN
- **设置**：网络拆 Value 流 + Advantage 流
- **你应该会看到**：同算力下收敛更快；V(s) 头可视化——它能"评估局面"而不只是"比较走法"
- **概念**：状态价值与动作优势分解（这个 V(s) 头是后来 AlphaZero value network 的直系祖先）

## E. 奖励设计（M4 提前开一扇窗）

### E10 奖励 shaping 对照
- **设置**：纯稀疏 vs 中间奖励（己方成四 +0.5、对方活三不挡 -0.3 之类）vs 势能差 shaping（γ-compatible 版本）
- **你应该会看到**：shaping 大幅加速早期爬升；但设计不当会"奖励作弊"（为吃 shaping 分放弃赢）
- **概念**：奖励假设、potential-based shaping 的不变性

## F. 预训练（稀疏奖励贴地的最狠解药）

### E11 行为克隆预训练 + RL 微调
- **设置**：先用 minimax 对局棋谱做监督学习（模仿学习）预训练策略头，再接 RL 微调；对照组 = 纯 RL 冷启动
- **你应该会看到**：起点胜率直接从 0% 跳到 30%+，总训练时间大幅缩短；但也继承 minimax 的保守风格，微调阶段要"洗"掉
- **概念**：off-policy 的另一个红利——旧数据/他人数据都能用

## 结课：天花板与换算法的动机

E1-E11 全部跑完后画一张总图：完整配方 + 各改进叠加的最好成绩 vs minimax-medium/hard 的差距曲线——**这条上不去的天花板，就是下一课（REINFORCE→A2C→PPO）换掉整个范式的理由**：Q-learning 是值方法，策略梯度直接在策略上爬坡，处理长视野连续决策更自然。到那时，"换算法的意义"不是新知识，是你在 E2/E3/E5 里亲手摸过的旧伤口。

## 基准赛考试（结课标准）

最终一代权重 vs minimax-easy / medium / hard 各 100 局（交替先手），逐代曲线 + 全部实验图 + 每图一段"我看到了什么、为什么"的笔记 = 这一课的交付物。
