# 《动手学现代强化学习》实验方法论参考

## 1. 指标体系

### 核心观测指标
该教程构建了完整的训练监控指标体系，分为六大类：
- **训练核心指标**：Loss（MSE TD Error）、Q值统计、梯度范数、探索率ε
- **奖励与性能**：回合奖励、平均奖励、滑动平均奖励、胜率
- **策略稳定性**：策略熵、KL散度、Clip Fraction
- **价值估计**：价值损失、价值预测均值与方差
- **资源效率**：训练速度、GPU利用率、显存占用
- **自博弈专属**：对手池多样性、ELO积分、策略迭代进度

### 呈现方式与健康信号
- **可视化**：训练曲线（奖励/损失）、热力图（Q值分布）、直方图（奖励分布）
- **日志记录**：每N步打印关键指标，保存为CSV/JSON
- **健康对照**：
  ✅ 健康：奖励稳步上升、熵缓慢下降、KL稳定、Clip Fraction < 0.3
  ❌ 危险：奖励暴跌、熵骤降/长期过高、KL飙升、梯度范数尖峰

## 2. 调试方法论

### 闭环调试框架
遵循“环境→数据→奖励→算法→评测”的分层排查顺序：
1. **先查环境接线**：确认状态/动作/奖励/终止信号正确，随机策略与弱专家策略有明显区分
2. **再查评测协议**：固定采样温度、batch size、评测集划分，避免评测污染
3. **后查奖励信号**：检查奖励分布是否合理，是否存在稀疏/极端/符号错误
4. **最后进入算法**：验证策略更新、价值函数拟合、探索机制是否正常

### 常见症状→病因→处方
| 现象 | 可能病因 | 解决方案 |
|------|----------|----------|
| Reward暴跌 | 策略崩溃、梯度爆炸 | 降低学习率、启用梯度裁剪、增大Clip范围 |
| KL飙升 | 更新步长过大 | 减小batch size、增加KL惩罚、降低学习率 |
| Entropy骤降 | 探索不足、Reward hacking | 增加熵正则、抽样检查高Reward样本 |
| 评测不涨但Reward上升 | 奖励信号偏差 | 人工抽检样本、分解奖励维度、加入惩罚项 |

## 3. 实验设计模式

### 标准实验体例
采用“问题→设置→预期→反例→结论”的五段式结构：
> **实验设置**：控制变量法，仅修改单个超参/组件
> **预期现象**：假设变化后的训练趋势
> **反例验证**：对比消融实验的负面结果
> **结论**：明确该组件/超参的作用边界

### 常用实验类型
- **对照实验**：固定其他参数，对比不同算法/超参的表现
- **消融实验**：逐一移除组件，验证其必要性（如去掉经验回放/目标网络）
- **超参搜索**：系统扫描学习率、batch size、探索率等关键参数

## 4. 写作体例示例

教程采用“你应该会看到”的直观教学体例：
> 【例1】“你应该会看到：训练初期奖励在-200附近震荡，约30k步后开始上升，最终稳定在200以上。曲线不单调，但整体脱离随机策略基线。”
> 
> 【例2】“你应该会发现：如果去掉目标网络，训练会变得极不稳定，Q值震荡幅度超过50%，甚至出现NaN损失。”
> 
> 【例3】“你应该能观察到：随着训练进行，策略熵从初始的0.693（随机策略）逐步下降到0.1以下，说明模型逐渐形成确定的动作选择策略。”

## 5. 自对弈/游戏特化方法论

针对游戏/自博弈场景，教程提出了专属观测体系：
- **对手池管理**：维护历史模型池，避免策略坍缩，随机抽取对手进行训练
- **强度评估**：ELO积分体系，衡量模型相对强度
- **多样性保证**：通过种群训练、随机对手选择维持策略多样性
- **迭代机制**：最新模型击败历史模型后，加入对手池，形成进化闭环

## 6. 五子棋DQN项目借鉴建议

1.  **核心指标**：记录回合奖励、胜率、策略熵、梯度范数、探索率
2.  **调试流程**：先验证环境正确性，再查奖励分布，最后排查算法问题
3.  **实验设计**：先做最小复现实验（随机策略→弱专家策略→完整DQN）
4.  **自博弈适配**：维护历史模型池，每N步保存一次checkpoint作为对手
5.  **观测重点**：不仅看胜率，还要看ELO积分变化、策略多样性
6.  **防坍缩措施**：加入熵正则、定期混合历史策略
7.  **可视化**：绘制奖励曲线、Q值分布热力图、胜率变化曲线
8.  **早停机制**：当KL散度超过阈值或奖励连续暴跌时停止训练
9.  **样本效率**：使用经验回放缓冲区，打破样本相关性
10. **稳健性**：加入梯度裁剪、奖励归一化等稳定训练
