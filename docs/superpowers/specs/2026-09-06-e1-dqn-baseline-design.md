# E1 · 15×15 完整配方 DQN 基线（快门派 A2）——设计文档

> 课 01 第二个实验。E0 已用表格 Q-learning 在 3×3 上完成概念验收；E1 把同一套
> 机制搬到 15×15，换成函数近似（神经网络），作为课 01 后续所有消融（E2-E11）
> 的**对照组基线**。本设计按 SOP 学习环走完全部 D1 设计决策 + D2 预言，工程环
> 将据此自动实现。
>
> 配套文档：`docs/course/01-dqn-outline.md`（E1 定义于 :17-21）、`docs/course/branching-sop.md`。

## 目标

在 15×15 棋盘上，训练一个**完整配方 DQN**：从零开始（冷启动）在稀疏终局奖励下
学会下五子棋。产出一条"长期贴地 → 缓慢爬升"的训练曲线，作为 E2 拆 replay、
E3 拆 target、E4 调 ε、E5 换对手池、E6 换容量、E7 调 γ 等所有消融的对照基准。

## 非目标（YAGNI）

- 不自对弈、不引入会学习的对手（非平稳性是 E5 主题）。
- 不做 reward shaping（E10）、不做行为克隆预训练（E11）。
- 不做 Double/Dueling DQN（E8/E9）。

## D1 设计决策定稿（八维）

> 全部为 `[决策·用户]`，Loop 讨论记录见会话 2026-09-06。标准记在 `branching-sop.md` 第 3.1 节。

### ① 奖励设计 —— 纯稀疏终局奖励
只有终局 `+1`（我方赢）/ `-1`（我方输）/ `0`（平）。中途每一步 0，不给中间打分。
依据：中途打分化身"替 agent 决定什么是好棋"，会奖励作弊。稀疏奖励同时也是 E1
"贴地"现象的第一来源——这正是本实验要亲眼体验的难度。（`e0-tabular.md:174-175`）

### ② 信用分配 —— TD + target network，γ = 0.99
- 更新用 TD 自举：`Q(s,a) → r + γ·max_a' Q_target(s',a')`，target 由滞后靶子网络给出。
- **γ = 0.99**（用户拍板），站在 E7 消融三档（0.9/0.99/0.999）正中间。
- 一局≤225 手，0.99 累计折扣因子下近端信用仍能回传远端（丢惩罚可忽略）。

### ③ 探索策略 —— ε-greedy 线性退火
- 起点 **ε=1.0**（全随机，最快铺状态空间），线性降到终点 **0.05**，之后钳在 0.05 永续探索。
- 退火在**总预算 60%（约 72 万局）**内烧完，后 40% 用终点值继续探索。
- 依据：前半段铺、后半段收，与 E0 终点一致。（`e0-tabular.md:180-193`）

### ④ 对手配置 —— B2：random 半 + minimax-easy 半（固定尺子，不入学习）
- 每一局以 50% 概率从 {random 脚本, minimax-easy} 中随机抽对手，从头到尾交错，无切换时机。
- 两个对手都是**死的、不学习的**脚本/AI——保证环境平稳（非平稳性是 E5 主题）。
- random 一半负责"喂形"：大量稀疏正反馈信号把初始动作形状喂成形。
- minimax-easy 一半负责"逼真格"：训练目标隐含"能赢这个固定标尺"，且与逐代基准赛
  同一对手，D3 读曲线时训练胜率与基准赛胜率直接对齐。
- minimax-easy 是 README 强调的"固定标尺"（衡量一切 RL 进步的基准）。

### ⑤ 状态表示 / 输入编码 —— 2 特征平面
- 输入 15×15×2：平面 0 = 己方落子，平面 1 = 对方落子，空位为 0。
- 行棋方由固定先手约定编码（训练方恒持黑先）。
- 依据：大纲"完整配方"定死（`01-dqn-outline.md:18`）。这是给 E6 加平面的基线锚点。

### ⑥ 网络结构与输出头 —— C2 小 CNN
- 2 层卷积 64ch + 全连接 64 → 输出 **225** 个动作 Q 值（每落点位一个），非法点以 mask 遮蔽、不参与 max。
- 依据：用户拍板 C2（贴合大纲"小 CNN"），给 E6 容量消融留对称锚点（E6 朝"极瘦/中宽"两侧移动）。
- 说明：大纲写"224 Q 值"，实为分区时 15×15=225 个落点位，取 mask 合法位，非纯字面 224。

### ⑦ 评估协议 —— 逐代基准赛
- 每代结束：当前 DQN vs random 20 局、vs minimax-easy 20 局，仅记录胜率，不影响训练。
- 每代同时记录：平均局长、训练 loss、策略熵、当前 ε。
- 记录入 `runs/e1/metrics.jsonl`（逐代追加），绘图脚本绘制逐代曲线。

### ⑧ 训练预算 —— A2 快门派
- **2 万局/代 × 60 代 = 120 万局自对弈**。
- 目标：本机 RTX 5060 Ti 上 30-60 分钟看到"贴地 → 爬升"。
- 依据：用户拍板 A2（贴地段与爬升点都够清晰，又不拖到失去教学节奏）。

### ＋ 工程件（用户授权既定）
| 项 | 值 |
|---|---|
| Replay buffer 容量 | 50 万条经验 |
| Target 更新节奏 | 每 1 万步从主网络复制一次 |
| 步学比 | 每走 1 步存 1 条、每 4 步学一次 |
| batch size | 256 |

## D2 预言（用户拍板稿）

> 训练前写，训练后逐条对照。标准记在 `branching-sop.md` 第 3.1 节节点 D2。
> 用户在训练前无概念，先给"凭感觉押"初稿，经纠正两个关键误会后校准：
> ①15×15 连五几乎无平局（非连三制）；②B2 无切换时机，两条曲线并行而非先后两段。

| 格 | D2 预言 |
|---|---|
| ① vs random | 开局 ~50%（乱下对乱下，先手略占优），爬得猛，很快到 80-90%，全程抖动向上 |
| ② vs minimax-easy | 非骤降而是从一开始贴合低位，前 30+ 代趴在个位数，后期才有起翘迹象 |
| ③ 平均局长 | 早期长（乱下填满才出线），学会快速连五后变短 |
| ④ loss 曲线 | 初始大、随训练下降但带噪声，target 每 1 万步刷新时小跳起 |

## 新增文件（工程环）

全部落在 `src/gomoku/rl/`：

| 文件 | 职责 |
|---|---|
| `dqn.py` | `DQNNet`（2×Conv64 → FC64 → 225，mask）；`ReplayBuffer`(50万)；Target 管理（每1万步复制） |
| `train_dqn.py` | 训练循环：采样对手(B2) → 走棋存经验 → 每4步学1次(batch256, γ0.99) → ε线性退火(1.0→0.05, 烧60%) → 纯稀疏奖励 |
| `evaluate.py` | 逐代基准赛：DQN vs random/minimax-easy 各 20 局，只记录不学习；写 metrics.jsonl + checkpoint |

复用不动：`core.py` 15×15 环境、`arena.Arena`、`players.minimax`（easy 尺子）、
`rl/tabular.py` 的绘图工具模式。
